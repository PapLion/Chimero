# Bundled resources

- `icon.png`, `icon.ico` — application icon.
- `exercises.json` — exercise catalogue used by the workout form. It is a slimmed
  copy (id, name, category, level, equipment, muscles, force, mechanic) of
  [free-exercise-db](https://github.com/yuhonas/free-exercise-db), which is released
  into the public domain (Unlicense). It is read from disk; the app makes no
  network requests.
